The cache key

A hit needs the same workspace, the same model, and the same exact prefix in the order tools → system → messages.

system
messages
new turn

Rule: a change invalidates its own segment and every segment to its right.

Design habits

  • Route in a separate request. The classifier never touches the conversation it routes.
  • Put per-route variation at the end. Append, don't edit.
  • Keep every tool defined, and restrict which ones the model may pick, instead of adding and removing tools (Manus: "mask, don't remove").
  • Choose the model at a boundary: conversation start or delegated task, never per turn.
  • No timestamps or per-request data in the prefix. Serialize JSON deterministically.
