Routing layers

Who decides what, and what each layer must keep sticky. Checked against the sources on 10 October 2026.

Placement rule

Give each decision to the layer that has the information it needs.

LayerQuestion it answersSeesKeep stickyExamples
Application What task is this, and who handles it? Meaning, conversation, task state Same model per conversation Classifier call, orchestrator delegating to subagents
Gateway Which deployment serves this model name now? Model names, provider health, rate limits, prices Same deployment or provider per conversation LiteLLM, OpenRouter
Server Which machine already holds this prefix? KV cache state, GPU load Same machine per conversation vLLM prefix caching, Gateway API Inference Extension endpoint picker

Costs to remember

  • Multi-agent systems used about 15x the tokens of a chat in Anthropic's Research system.
  • Failing over to another provider starts with a cold cache.
  • Prefix caching speeds up prefill only, not generating output tokens (vLLM).
